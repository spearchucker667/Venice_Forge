# Reports Directory

This directory contains historical test, validation, and security audit reports for Venice Forge.

## Report Governance

Active work orders and tasks are never tracked in reports; they belong in [`docs/ROADMAP.md`](../ROADMAP.md). Session progress belongs in [`docs/summary_of_work.md`](../summary_of_work.md).

All past audit and test reports are preserved as non-authoritative historical evidence in:

👉 **[`historical/`](historical/)** — Contains completed historical audit reports, bug hunt summaries, and remediation reports.

Refer to [`historical/CANONICAL_REPORT_INDEX.md`](historical/CANONICAL_REPORT_INDEX.md) for the master index of all archived reports.
