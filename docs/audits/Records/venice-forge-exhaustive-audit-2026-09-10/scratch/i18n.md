### VF-AUD-20260910-I18-001

- **Class:** confirmed defect
- **Severity:** P1
- **Symbols:** `src/i18n/resources/{es,fr,de,pt-BR,ru,zh-CN,ja,hi,ar,ko,sv-SE}/**/*.json` — 66 keys, including `common:actions.saveAs`, `common:mediaSave.*`, `common:safetyDecision.*`, `media:contextMenu.*`
- **Observed:** Every non-English catalog stores 66 values prefixed `Tr: ` plus the English source string. Example (`src/i18n/resources/es/common.json`):

```40:46:src/i18n/resources/es/common.json
    "saveAs": "Tr: Save As…",
    "lock": "Tr: Lock",
    "favorite": "Tr: Favorite",
    "unfavorite": "Tr: Unfavorite",
    "regenerate": "Tr: Regenerate",
    "download": "Tr: Download",
    "open": "Tr: Open"
```

These are **not** identical to en-US (`"Save As…"`), so they count as translated. Runtime normalizer does not scrub `Tr:`, so the UI renders the prefix. Callers include `tRuntime("actions.saveAs")` in `src/components/image/image-view.tsx` and `formatSafetyDecision()` in `src/shared/safety/formatSafetyDecision.ts` (safety-block copy).

- **Expected:** Non-English catalogs contain real translations, or untranslated markers that fall back to en-US without a visible `Tr:` prefix. Safety and media strings must never show translator scaffolding.
- **Evidence:** 66 unique keys × 11 locales = **726** leaves. Split: common 40, settings 13, media 11, chat 2. Present in all 11 locales. en-US has 0. `npm run verify:i18n` exit 0.
- **Reproduction:** Static catalog scan `/^\s*Tr:\s/`. Render Image Studio save-as / Media Studio export / a Family Safe Mode block under `es`.
