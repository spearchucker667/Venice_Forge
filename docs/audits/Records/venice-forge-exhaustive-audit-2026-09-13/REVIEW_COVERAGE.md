## 2. Directory Breakdown & Review Methodology

### 2.1 Electron Main Process (`electron/` — 225 files)
- **Review Mode:** Line-by-line semantic inspection of all security-sensitive, storage, IPC, and lifecycle files.
- **Key Modules Inspected Line-by-Line:**
  - `electron/main.ts`: Window creation, sandbox webPreferences, CSP header interception, navigation guards, custom protocol handlers (`venice-media:`, `venice-tts:`, `venice-character-cache:`), signal handlers, single instance lock.
  - `electron/preload.ts`: `contextBridge` exposure, parameter validation, channel mapping.
  - `electron/ipc/handlers/*`: All 190 registered IPC channels, sender validation (`validateIpcSender`), rate-limiting, error normalization.
  - `electron/services/*`:
    - `conversationVault.ts`: AES-256-GCM encryption, key wrapping via `safeStorage`, journal compaction, quarantine logic.
    - `chatStorage.ts`, `chatFolderStorage.ts`: Durability, atomic write migration.
    - `syncFolderWatcher.ts`, `syncBridge.ts`, `remoteApplyAuthority.ts`: Packet ingestion, grant minting, tombstone validation.
    - `providerSettingsStore.ts`, `secureStore.ts`: OS encryption, DPAPI/Keychain integration, plaintext prevention.
    - `backgroundTaskManager.ts`: Video/audio queue management, recovery on restart.
    - `mediaService.ts`, `characterImageCache.ts`: Path traversal checks (`checkPathContained`), descriptor-safe reads (`O_NOFOLLOW`).
  - `electron/utils/atomicFileReplace.ts`: Multi-platform atomic replace, `syncTempFile`, copy+unlink Windows fallback.

### 2.2 Renderer Layer (`src/` — 1,024 files)
