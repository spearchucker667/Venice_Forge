# Repository Maintenance & Hygiene

This directory preserves the current repository-hygiene report plus dated move and deletion manifests. It is a documentation record, not a second roadmap; current unfinished work belongs in [`../ROADMAP.md`](../ROADMAP.md). Historical audit findings remain evidence only and do not override current source or tests.

## Documents

- [`REPOSITORY_HYGIENE_REPORT.md`](REPOSITORY_HYGIENE_REPORT.md) — Comprehensive repository hygiene audit, modernization findings, `.gitignore` / `.gitattributes` / `.editorconfig` audit, and validation matrix.
- [`FILE_MOVE_MANIFEST.md`](FILE_MOVE_MANIFEST.md) — Exact manifest of relocated and renamed paths, rationale, reference checks, and validation results.
- [`DELETION_MANIFEST.md`](DELETION_MANIFEST.md) — Audit record of candidate deletions, historical removals, and removal criteria enforcement.
